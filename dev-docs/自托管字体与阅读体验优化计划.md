# 字体方案与剩余优化空间

**更新日期**: 2026-09-16
**状态**: 当前方案已固化（build 验证通过）

> 本文档原为「自托管字体与阅读体验优化计划」，其中的步骤已全部执行或废弃（衬线方案曾短暂上线后被移除）。现改写为当前字体方案的说明与剩余优化空间。

## 1. 当前方案

全站使用无衬线字体，分两层：

- **西文与数字**：系统栈（`-apple-system` / `Segoe UI` / Roboto 等），零加载成本
- **中文**：自托管 `MiSans`（400/500/700），`Noto Sans SC` 与系统中文字体（PingFang SC / 微软雅黑）作为兜底

`src/styles/global.css` 中的字体变量：

```css
--font-sans:
  -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto,
  "Helvetica Neue", Arial, "MiSans", "Noto Sans SC",
  "PingFang SC", "Microsoft YaHei", sans-serif;
--font-mono:
  "JetBrains Mono", "SFMono-Regular", Consolas, "Liberation Mono", monospace;
```

body 与标题统一使用 `var(--font-sans)`（标题靠字重 600 区分层级），代码使用 `var(--font-mono)`。

## 2. 字体文件现状

`public/fonts/` 下只保留 sans 字体：

```text
MiSans-Regular.woff2   4.7M   font-weight 400
MiSans-Medium.woff2    4.8M   font-weight 500
MiSans-Bold.woff2      4.9M   font-weight 700
NotoSansSC-*.woff2     12-28K 已子集化的兜底
```

此前的 EB Garamond / Noto Serif SC 衬线文件（约 30MB ttf）已随 serif 方案一起删除。

## 3. 剩余优化空间

MiSans 三个字重共约 14.4MB，是全站最大的静态资源。可选的后续优化：

- **子集化**：按实际页面字符（或常见汉字集）裁剪 MiSans，预计可降到每个字重几百 KB
- **减少字重**：500（Medium）目前只用于 eyebrow 小字，可考虑回退到 400/700 两字重，直接省 4.8MB
- **按需加载**：中文页面才声明 MiSans @font-face（需要按语言拆 CSS，收益与复杂度需权衡）
- **preload**：首屏关键字重加 `<link rel="preload">`，减少字体闪烁

不做子集化时，Cloudflare Pages 的 CDN 缓存 + `font-display: swap` 已能保证可接受的实际体验。

## 4. 阅读体验相关约定（现行）

- 全站统一 52rem（832px）中轴，Header / Footer / 首页 / 列表 / 详情共用
- 详情页面包屑与 meta 行使用 0.8rem `var(--text-subtle)` 小字（无 emoji 图标）
- rich-content 正文行高 1.78，标题字重 600
- 列表条目为无盒子的平面行，条目间用发丝分隔线
